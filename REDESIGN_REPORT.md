# Редизайн FreedomBrowser по референсу

## Freedom Browser 0.6: что добавлено во втором проходе
- **FRC в новом стиле.** Поповер стал шире (420px); «Сбалансированный» больше не рвётся посреди слова; монохромные сегменты; основная кнопка в акцентном цвете; версия берётся из `src/version.ts`. Страница `freedom://memory` и диспетчер задач перекрашены через токены. Цвета sky/purple сведены к монохрому, а скругления xl/2xl/3xl — к токенам, всё через `@theme` в `index.css`.
- **Главное меню.** Шире, сочетания клавиш не переносятся, иконки монохромные. Добавлены переключатели «Блокировка всплывающих окон», «Защита от трекеров» и «Не отслеживать», как в референсе. Они управляют теми же настройками, что и в разделе «Приватность».
- **Настройки.** Слева логотип и версия, пункты списком с шевронами, новый раздел «О браузере». По умолчанию открывается «Основные».
- **Панели.** Загрузки, история и закладки открываются под тулбаром и больше не перекрывают вкладки и кнопки окна.
- **Быстрые ссылки** на новой вкладке можно переставлять перетаскиванием (`FavoritesService.moveFavorite`).
- **Брендинг.** Версия 0.6 (`package.json`: semver `0.6.0`). productName — «Freedom Browser». Имена артефактов: `Freedom-Browser-0.6-x86_64.AppImage` и `Freedom-Browser-0.6-x64.exe`. В «О браузере», `metadata.json` и `index.html` исправлено описание стека (было «Rust/Tauri/WebKitGTK», на деле Electron/Chromium).

### Исправленные баги
1. Настройки «Do Not Track», «Блокировать сторонние cookie» и «Блокировать всплывающие окна» ни на что не влияли. Теперь renderer передаёт их в main по IPC (`set_privacy_settings`). Там отправляются заголовки `DNT: 1` и `Sec-GPC: 1` (проверено на httpbin.org: заголовок есть, при выключении пропадает), у межсайтовых подзапросов убираются `Cookie` и `Set-Cookie`, а окна `window.open` с параметрами (`disposition: new-window`) блокируются; обычные `_blank`-ссылки по-прежнему открываются во вкладках.
2. После перехода со стартовой страницы на сайт кнопка «Назад» была неактивна. Теперь она возвращает на новую вкладку.
3. Если у сайта нет фавиконки или она битая, вместо пустого места во вкладке показывается монограмма.
4. Папка `build/icons` не попадала в пакет, и у окна не было иконки. Теперь она добавлена в `build.files`. Кроме того, она была в `.gitignore`, поэтому CI собирал без иконок.
5. Цвет фона окна при запуске совпадает с темой (без чёрной вспышки).

### Сборка и проверка 0.6
- Linux: `npm run build:appimage` собирает `release/Freedom-Browser-0.6-x86_64.AppImage`. Запуск проверен: smoke-test PASS, через CDP открыта стартовая страница, переход на example.com, «Назад», FRC, меню, настройки.
- Windows: локально собрать нельзя (electron-builder требует `wine`, а его нет). Сборка `.exe` и его реальный запуск (`--smoke-test`, проверка, что UI смонтирован) выполняются в GitHub Actions на `windows-latest` (`.github/workflows/release.yml`). Готовый exe workflow прикладывает к релизу.
- `--smoke-test`: приложение загружает интерфейс, проверяет сайдбар и омнибокс и завершается с кодом 0 или 1.

### Известное
- `ERR_ABORTED (-3)` в консоли при первом переходе. Ошибка была и до редизайна: адрес одновременно задаётся через атрибут `src` у `<webview>` и через `loadURL`. Страница грузится нормально; исправление требует переделки загрузки webview.
- Виджета погоды нет: нужен внешний API или ключ. Вместо него часы.
- Часть строк в FRC (например «PSS Non-Dup», «Sleep», «State 1…») по-прежнему не переведена.

## 3. Как устроена централизация
- Все токены находятся в `:root` в `src/index.css`.
- `@theme inline` перенаправляет шкалы Tailwind `neutral-*` и `emerald-*` (около 800 использований в 20 файлах) на токены. Поэтому все экраны (диалоги, дроверы, Task Manager, FRC, страница ошибки, split view) перекрасились без правки каждого класса.
- `App.tsx` функцией `paletteToTokens()` пишет палитру выбранной темы в `--fb-*` (на `#freedom-browser-app` и `<html>`, чтобы порталы тоже получали цвета).
- Захардкоженные hex-фоны (`bg-[#12141c]` и подобные) в компонентах заменены на `var(--fb-surface)` и `var(--fb-bg)`.
- Чекбоксы глобально оформлены как переключатели, как в меню и настройках референса. У `select` и `:focus-visible` тоже единый стиль.

## 5. Перенесённые элементы (ничего не удалено)
- Кнопки «Домой», «Найти», «Закладки», «История», «Загрузки» скрыты в тулбаре (CSS в `index.css`). Домой, закладки, история и загрузки теперь в сайдбаре (счётчик активных загрузок показан там же). Всё это и поиск по странице по-прежнему доступно из главного меню и по горячим клавишам.

## 6. Допущения и отличия от референса
- **Фоновая фотография гор** из референса не копировалась. Вместо неё нарисован собственный фон на CSS и SVG: световой луч и силуэты хребтов. Пользовательские обои из настроек по-прежнему работают.
- **Виджет погоды** не сделан: ему нужен внешний сетевой API, а это противоречит приватности браузера. На его месте часы.
- **Превью страниц** в обзоре вкладок заменены фавиконками. Снимки `capturePage` для каждой вкладки потребовали бы правок в логике и памяти (FRC).
- **Тулбар.** Кнопки FRC (RAM), Split View и DevTools оставлены, потому что это уникальные функции браузера. В референсе на этом месте два значка.
- **Маскот Freen** (настройка `showFreenMascot`) в референсе отсутствует. Он оставлен как есть, его можно выключить в «Темы и оформление».
- **Цвета референса** сняты на глаз с JPEG, точность около ±5%.
- **Inter** не встроен в сборку, чтобы не добавлять ~300 КБ. Без него используется системный sans.

```bash
npm install

npm run electron:start # запуск
npm run build:appimage # AppImage (Linux)
npm run build:win      # Windows portable/zip
```
AppImage и exe в корне проекта **не пересобирались**: в них по-прежнему старая версия.

## 9. Известные ограничения и что можно доработать
- Не проверены вручную: настоящий Wayland/KDE, HiDPI, перетаскивание окна за полосу вкладок, приватный режим (в коде отдельного UI для него не найдено).
- Часть цветных иконок в меню сортировки (sky/rose/amber) оставлена: это семантические цвета.
- Устаревшие настройки `headerColor` и `backgroundColor` больше не влияют на полосу вкладок и тулбар, их заменяет палитра темы.
- Можно добавить светлую тему: достаточно второго набора токенов.
